# QA evidence index

This directory holds the real-browser visual evidence for draft PR #6 (`rework/3d-room`): 28 PNG screenshots under `screenshots/` and 3 WebM recordings under `recordings/`, captured from the built site in headless Chromium with SwiftShader WebGL2 across desktop (1440×900), tablet (768×1024) and mobile (390×844 @2, touch) viewports. Coverage includes default 3D for every zone, forced 2D, all static fallback gates (reduced-motion / no-WebGL2 / save-data / scene-failed), mobile portrait framing, the delayed-chunk loading indicator, and the four 3D detail dialogs, plus clips of camera navigation, the 3D↔2D shell handoff and a mobile zone tap. Open `REPORT.md` for the full pass/fail matrix, WebGL2/tooling details, honest defect list and reproduction steps; key screenshots are embedded directly in the PR comment for quick review.
